# คู่มือทดสอบการเชื่อมต่อ EASpaze กับ MT5

## ไฟล์นี้ทำอะไร

`EASpazeConnectivityProbe` เป็น EA สำหรับทดสอบการเชื่อมต่อแบบ **อ่านข้อมูลอย่างเดียว** มันจะถาม Supabase ของ EASpaze ทุก 15 วินาทีว่ามี Strategy ที่แชร์เป็นสาธารณะหรือไม่ และแจ้งในแท็บ **Experts** เมื่อได้รับข้อมูลใหม่

EA ตัวนี้ **ไม่มีคำสั่งเปิดหรือปิดออเดอร์** และยังไม่ใช่ EA Engine สำหรับเทรดจริง

## สิ่งที่ต้องเตรียม

- เปิด MT5 บน **บัญชี Demo** และเลือก chart ที่จะใช้ทดสอบ
- ใช้ไฟล์ `.ex5` ที่ compile แล้ว หรือไฟล์ `.mq5` สำหรับ compile เอง
- เตรียมค่า **Publishable Key** จากหน้า Supabase ของโปรเจกต์ EASpaze
- เตรียม Strategy ทดสอบที่ยินดีแชร์เป็นสาธารณะในหน้า Explore

> อย่านำ Strategy ที่ต้องการเก็บเป็นส่วนตัวมาใช้ทดสอบ เพราะ probe จะอ่านเฉพาะรายการที่แชร์แบบสาธารณะ แต่ใครก็ตามที่เข้า Explore ก็อาจมองเห็น Strategy ที่เผยแพร่ได้

## ตั้งค่า WebRequest ใน MT5

1. ใน MT5 เปิดเมนู **Tools → Options**
2. เลือกแท็บ **Expert Advisors**
3. เปิดตัวเลือก **Allow WebRequest for listed URL**
4. เพิ่ม URL นี้ในรายการ แล้วกด **OK**:

   `https://ugkfmlzqhdqdmbsscjfp.supabase.co`

## เพิ่ม EA ลงใน MT5

1. ใน MT5 เลือก **File → Open Data Folder**
2. เปิดโฟลเดอร์ `MQL5` แล้วเปิด `Experts`
3. คัดลอกไฟล์ `EASpazeConnectivityProbe.ex5` เข้าไปในโฟลเดอร์นั้น
4. กลับไปที่ MT5 เปิดแผง **Navigator** คลิกขวาที่ **Expert Advisors** แล้วเลือก **Refresh**
5. ลาก `EASpazeConnectivityProbe` ไปวางบน chart ของบัญชี Demo
6. ในหน้าต่างตั้งค่า เปิดแท็บ **Inputs** แล้ววาง Supabase **Publishable Key** ลงในช่อง `InpPublishableKey`
7. ปล่อย `InpPollSeconds` เป็น `15` แล้วกด **OK**

ใช้เฉพาะ Publishable Key จาก Supabase เท่านั้น ห้ามใส่ `Secret key`, `service_role key`, รหัสผ่านบัญชีเทรด หรือข้อมูลลับอื่นลงใน EA

ถ้า EA ไม่ปรากฏใน Navigator ให้ตรวจว่าคัดลอก `.ex5` ไปไว้ใน `MQL5/Experts` ของ MT5 ตัวเดียวกับที่กำลังเปิดอยู่ จากนั้นเลือก **Refresh** อีกครั้ง

## ดูผลการทดสอบ

เปิดแท็บ **Experts** ด้านล่างของ MT5:

- ถ้าเชื่อมต่อสำเร็จ จะเห็น `HTTP 200` และข้อความว่าได้รับข้อมูล Strategy ใหม่ หรือข้อมูลยังไม่เปลี่ยน
- ถ้าระบบตอบว่าไม่พบ Strategy สาธารณะ ให้ไปที่เว็บ สร้าง Strategy สำหรับทดสอบ และเปิด **แชร์ใน Explore** จากนั้นกดบันทึก
- เมื่อต้องการทดสอบการอัปเดต ให้แก้ Strategy ทดสอบบนเว็บแล้วบันทึก รอไม่เกินหนึ่งรอบตรวจสอบ คือประมาณ 15 วินาที แล้วดูแท็บ **Experts** ว่ามีข้อความว่าได้รับ payload ใหม่หรือไม่

หากเห็น error ให้ส่งภาพแท็บ **Experts** มาได้ โดยปิดบัง Publishable Key หรือข้อมูลบัญชีอื่นก่อน

## ข้อจำกัดของการทดสอบนี้

- ต้องติด EA ไว้บน chart ในหน้าต่าง MT5 ปกติ และปล่อย terminal ทำงานอยู่
- **WebRequest ใช้ใน Strategy Tester ไม่ได้** จึงไม่สามารถทดสอบ probe นี้จากหน้า Strategy Tester
- การทดสอบนี้ยืนยันเพียงว่า MT5 ติดต่อ Supabase ซ้ำ ๆ และรับข้อมูล Strategy สาธารณะได้ ยังไม่ทดสอบการจับคู่บัญชีส่วนตัว การสั่งเริ่มเทรด การส่งคำสั่งซื้อขาย หรือการสั่ง Backtest จากหน้าเว็บ
- ขั้นถัดไปสำหรับการเชื่อมต่อจริงคือออกแบบการ pair เครื่องกับบัญชีผู้ใช้ การยืนยันสิทธิ์ของ EA และช่องทางสั่งงานที่ปลอดภัย
